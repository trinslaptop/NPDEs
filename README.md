# Numerical Solutions to Partial Differential Equations
My work for [Math550](https://github.com/numberFactory/MATH550_textbook). Each HW is in it's own folder.

Each directory contains:
+ An `.ipynb` Jupyter notebook
+ A `README.md` and an equivalent `README.pdf` (albeit with some formatting differences)
+ A `./content` folder of images and any misc files

In general, `README.pdf` is generated from `README.md` which is generated from the `.ipynb`; however, there's still a bit of manual work between these steps (scripts coming soon?).
